How It Works

STFT
Spectrogram
SHA1
Hashing
O(1)
Lookup
SQLite
Storage

1. Audio → Short-Time Fourier Transform → Spectrogram
2. Extract dominant frequency peaks (constellation map)
3. Pair peaks → generate SHA1 hashes with time deltas
4. Lookup hashes in SQLite index (900k+ entries)
5. Time-offset alignment voting → best match wins
6. Confidence = matched hashes ÷ total query hashes
